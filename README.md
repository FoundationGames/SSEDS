# SSEDS: Simple Synchronized Entity Data Serializers
### Mod for Minecraft using the Fabric Mod Loader

## The Problem
- Minecraft Entity Data Serializers are given IDs in the order they are registered.
- Fabric mods sometimes need to register their own Entity Data Serializers.
- Mod load order is unreliable, and as such the order and IDs of modded Entity Data Serializers is as well.
- This will create packet errors should a server and client not have the same mod load order.
- Forge, NeoForge, and Quilt all have APIs to fix this, Fabric still does not.

## The Solution
- SSEDS makes Entity Data Serializers rely on a conventional synchronized Fabric registry with namespaced IDs for each serializer.
- However, for mods that register data serializers the vanilla way, a namespaced ID will be generated by figuring out which mod is registering each serializer.
